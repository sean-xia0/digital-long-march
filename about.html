数字长征 · 历史专题1934 — 1936
PROJECT STATEMENT作品 / 05

码承长征薪火 · 页绘青春征途

让历史被看见，
让技术有温度。

《数字长征：永不熄灭的征途》是一项以网页为媒介的数字历史叙事设计。作品尝试将时间线、路线档案、人物资料和青年表达组织为可探索的线上展览。

设计理念

电影感叙事 · 档案式信息

以深红、炭黑、旧金色构建整体视觉语言；通过留白、章节编号、时间刻度与交互卡片，让页面兼具历史厚重感和数字阅读体验。

技术实现

原生 Web 技术

采用 HTML5 语义结构、CSS 响应式布局与原生 JavaScript 交互。无需框架和构建步骤，便于评审直接运行、查看与维护。

内容原则

来源可查 · 口径清晰

按部队区分长征路线与时间；重要事件提供来源链接；示意地图明确标注非比例，不将视觉推演冒充史实。
