# 数字长征｜永不熄灭的征途（V14.8 纪录片章节播放版）

电影级史诗风格的数字历史专题网站，以时间轴、四路红军路线、人物档案和史料索引呈现长征历史。

- **在线作品：** https://sean-xia0.github.io/digital-long-march/
- **路线探索：** https://sean-xia0.github.io/digital-long-march/routes.html
- **源代码仓库：** https://github.com/sean-xia0/digital-long-march

## 页面结构

| 页面 | 文件 | 内容 |
|---|---|---|
| 首页 | `index.html` | 电影感首屏、专题导航、主题表达 |
| 历史时间轴 | `history.html` | 代表性历史节点 |
| 路线探索 | `routes.html` | 四路红军筛选、12个历史节点、五章纪录片式播放、同步字幕、章节定位、镜头自动聚焦与地图联动 |
| 人物档案 | `people.html` | 八位人物长征时期职务与行动摘要 |
| 史料档案 | `archives.html` | 党史、军史、档案与专题来源入口 |
| 作品说明 | `about.html` | 设计理念、技术实现、运行与版权边界 |

## 本地运行

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，或下载 main 分支归档。
2. 解压后保持文件夹结构不变。
3. 直接打开 `index.html`。
4. 无需 npm install、依赖安装或构建命令。

页面结构、样式、脚本、路线示意图与原创 SVG 插画使用本地资源；史料档案页两张 CC BY-SA 4.0 当代摄影通过 Wikimedia Commons 远程加载，官方史料外链也需联网。因此断网时网站主体和地图交互可运行，但两张照片及外链内容不可用。

## 技术实现

- HTML5、CSS3、原生 JavaScript。
- 本地 SVG 2.5D 地形路线图：立体倾角、动态路线、四路筛选、河流/山脉注记、节点坐标与相邻节点直线距离；不依赖在线地图瓦片、Leaflet CDN 或远程字体。
- 纪录片播放支持五个章节、逐事件历史字幕、章节跳转与延长镜头停留节奏。
- 响应式页面、移动端导航、键盘焦点、路线筛选与事件详情联动。
- 无构建步骤，目录结构可直接运行。

## 地图功能与数据边界

- 地图新增经纬网、指北针、主要河流与地貌名称注记，以及可暂停的路线动态效果。
- 立体效果由 SVG 与 CSS 透视变换实现，属于 2.5D 视觉表达，不是可测量的三维地形模型。山脉阴影、河流线均为示意；未使用 DEM 高程栅格或精确水系 GIS 数据。
- 地点详情显示现代地名参考坐标；相邻节点距离为球面直线距离，不是历史行军里程。

## 史实与地图口径

- 不混淆不同部队的长征路线、时间与会师关系。
- 红二十五军永坪进程区分1935年9月15日抵达与9月16日正式会师。
- 红二、红六军团甘孜会合采用“1936年6月下旬—7月2日”的谨慎表述。
- 达维先头部队会师与中央红军主力到达懋功分阶段呈现。
- 会宁（1936年10月9日）与将台堡（1936年10月22日）分开呈现。
- 地图点采用现代城市、县城或县域参考坐标；连线仅表示代表性地点关系，不是完整历史行军轨迹或精确旧址测绘。

## 图片与视觉素材

- 新增四幅原创 SVG 艺术示意插画：群山行军、强渡江河、翻越雪山、胜利会师。

## V14.2 历史路线时间播放模式

- 路线时间线新增播放/暂停、上一事件/下一事件、播放速度选择和可拖动进度条。
- 播放时按既有12个史料节点的顺序切换路线筛选、地图地点高亮、事件详情和对应史料来源；手动点击时间线也会同步进度。
- 播放默认由用户主动启动，不自动播放；用户可随时暂停或拖动定位。减少动态效果偏好仍会关闭地图装饰动画。
- 该功能只演示既有历史节点，不补造节点之间的行军轨迹或时间细节。
