# 数字长征｜永不熄灭的征途（V10.2.1 最终参赛版）

电影级史诗风格的数字历史专题网站，以时间轴、四路红军路线、人物档案和史料索引呈现长征历史。

- **在线作品：** https://sean-xia0.github.io/digital-long-march/
- **路线探索：** https://sean-xia0.github.io/digital-long-march/routes.html
- **源代码仓库：** https://github.com/sean-xia0/digital-long-march

## 页面结构

| 页面 | 文件 | 内容 |
|---|---|---|
| 首页 | `index.html` | 电影感首屏、专题导航、主题表达 |
| 历史时间轴 | `history.html` | 代表性历史节点 |
| 路线探索 | `routes.html` | 四路红军筛选、12个关键时间线节点、地图联动 |
| 人物档案 | `people.html` | 八位人物长征时期职务与行动摘要 |
| 史料档案 | `archives.html` | 党史、军史、档案与专题来源入口 |
| 作品说明 | `about.html` | 设计理念、技术实现、运行与版权边界 |

## 本地运行

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，或下载 main 分支归档。
2. 解压后保持文件夹结构不变。
3. 直接打开 `index.html`。
4. 无需 npm install、依赖安装或构建命令。

网站页面、样式、脚本和路线示意图使用本地资源，网站主体可离线运行；点击官方史料外链时需要网络。

## 技术实现

- HTML5、CSS3、原生 JavaScript。
- 本地 SVG 地图示意图，不依赖在线地图瓦片、Leaflet CDN 或远程字体。
- 响应式页面、移动端导航、键盘焦点、路线筛选与事件详情联动。
- 无构建步骤，目录结构可直接运行。

## 史实与地图口径

- 不混淆不同部队的长征路线、时间与会师关系。
- 红二十五军永坪进程区分1935年9月15日抵达与9月16日正式会师。
- 红二、红六军团甘孜会合采用“1936年6月下旬—7月2日”的谨慎表述。
- 达维先头部队会师与中央红军主力到达懋功分阶段呈现。
- 会宁（1936年10月9日）与将台堡（1936年10月22日）分开呈现。
- 地图点采用现代城市、县城或县域参考坐标；连线仅表示代表性地点关系，不是完整历史行军轨迹或精确旧址测绘。
