# 数字长征｜永不熄灭的征途（V6 离线提交版）

以 HTML、CSS、原生 JavaScript 构建的响应式数字历史专题网站。**网站页面、样式、脚本与路线地图均为本地资源，断网也可打开和交互。** 无需安装 npm 依赖或执行构建命令。

## 页面结构

```text
digital-long-march/
├── index.html              # 电影感首页
├── history.html            # 历史时间轴
├── routes.html             # 四路红军路线专题与离线坐标图
├── people.html             # 人物档案
├── archives.html           # 史料档案与来源入口
├── about.html              # 作品说明与技术信息
├── css/                    # 本地样式
├── js/                     # 本地交互脚本
├── PROJECT-BRIEF.md        # 作品摘要与演示顺序
├── CREDITS.md              # 素材来源与许可说明
└── SUBMISSION-CHECKLIST.md # 参赛检查清单
```

## 离线运行

1. 解压 `digital-long-march-v6-offline.zip`。
2. 保持文件夹结构不变，直接打开 `index.html`。
3. 首页、五个子页面、移动端导航、路线筛选、地图节点说明均使用本地文件，可在断网环境运行。
4. 页面中的官方史料来源链接属于外部网页，点击阅读时需要网络；这不影响网站本体运行。
5. 字体使用设备系统字体栈，不会请求 Google Fonts；地图不加载 Leaflet CDN、在线瓦片或其他远程脚本。

## V6 离线化改动

- 移除 Google Fonts 远程字体请求，改用系统中文字体栈。
- 移除 Leaflet CDN 与 OpenStreetMap 在线瓦片依赖。
- 路线图改为本地 SVG，使用已整理的现代地名参考经纬度绘制相对位置。
- 保留四路红军筛选、节点点击、键盘操作、地点说明和经纬度信息。
- 地图状态明确显示为离线坐标示意图；不把连线解释为精确历史行军轨迹。
- 保留官方史料链接，方便联网时查证。

## 地图口径与限制

地图采用现代城市、县城或县域参考坐标，不等同于 1930 年代具体驻地、渡口、战斗点或会师旧址的精确坐标。虚线仅连接代表性节点，不能视为完整行军路线、道路或里程。页面保留相应说明。坐标位置参考 OpenStreetMap 公开地名数据；本版本不加载 OSM 底图瓦片。

## 史实与版权原则

- 不把不同部队的长征起止时间、路线和会师节点混为一谈。
- 1936 年 10 月 9 日：红一、红四方面军在甘肃会宁会师。
- 1936 年 10 月 22 日：红一、红二方面军在将台堡会师。
- 首页路线图为非比例示意图；路线页坐标图也不是历史轨迹复原。
- 当前压缩包不包含未经核实授权的历史照片、人物肖像或扫描档案。
- 网页可访问不自动意味着图片、地图或档案可自由转载。
